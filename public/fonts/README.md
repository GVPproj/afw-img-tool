# Iosevka font assets

Self-hosted Latin-subsetted WOFF2 fonts copied from the AFW website, from [Iosevka v34.9.0](https://github.com/be5invis/Iosevka/releases/tag/v34.9.0), licensed under [SIL OFL 1.1](iosevka-LICENSE.md). Subsets were made with fonttools 4.63.0 and brotli 1.2.0; expand character coverage from the upstream release, not these subsets. Font and fallback declarations are in `src/styles.css`; generic fallbacks remain unadjusted when named local fonts are unavailable. After font or heading changes, check mobile/desktop wrapping before and after fonts load, including platform fallbacks.
